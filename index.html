About This Project

VibeAviate is a CIS 51 vibe-coding project at De Anza College: a browser front end for an OpenFlights air travel database.

The Data

How It Works

The whole app is a single HTML file. The airline, airport and route records are built into it, so every lookup and report runs instantly in your browser without a server. The interactive 3D globes and the charts are drawn with D3.js, and the globes use Natural Earth country outlines. Distances are calculated with the haversine formula, using Earth's mean radius of 3,958.8 miles.
